# Nocturne UI 1.14

Компактное меню на Luau для клиента Roblox. Размер демонстрации — 530 × 620.

- Сетка и отступы по референсу: две колонки, тонкие рамки, точечный фон, небольшие шрифты и поля с отступом под текстом чекбокса.
- На первой вкладке полностью помещаются `players models`, `world modulation`, `players master`, `general` и `extra`, включая `day sky` / `night sky`.
- Colorbox: поле насыщенности/яркости, оттенок, прозрачность на шахматном фоне, предпросмотр, RGBA/HEX и десять общих ячеек галереи.
- Сохранены вкладки, подкатегории, подсказки, режимы клавиш, изменение размера, конфигурации и публичные методы контролов.

## Запуск

**Один файл:** `Demo.lua` содержит библиотеку и демонстрацию вместе. Его можно открыть или скачать прямо из GitHub; отдельный файл библиотеки для этого варианта не нужен.

**Roblox Studio:** создайте в `StarterPlayer > StarterPlayerScripts` ModuleScript с именем `Nocturne` и вставьте в него содержимое `Nocturne(2).lua`. Рядом создайте LocalScript и вставьте `Example(2).lua`. Запустите Play. Без поддержки пользовательских шрифтов библиотека использует Arial; точная форма букв зависит от доступного шрифта.

**Среда с поддержкой файлов:** сохраните `Nocturne(2).lua` в рабочую папку и выполните `Example(2).lua`. Пример сначала ищет локальную библиотеку, затем загружает её из `tanchdenis/jopahack4/main`. Для проверки ветки до слияния используйте локальный файл библиотеки.

`Right Shift` скрывает/показывает меню. Клик по образцу цвета открывает colorbox; `Esc` или клик снаружи закрывает его. `Aa` переключает RGBA и HEX. Поддерживаются `103, 187, 117, 255`, `#67BB75` и `#67BB75FF`. Некорректный ввод восстанавливает прежнее значение. Галерея хранит цвет и прозрачность, общая для всех colorbox данного окна и действует до его закрытия.

`ColorGallery` в `CreateWindow` задаёт начальные образцы (до десяти):

```lua
ColorGallery = {
    Color3.fromRGB(255, 0, 0),
    { Color = Color3.fromRGB(103, 187, 117), Alpha = 0.5 },
}
```

У `AddColorPicker` можно указать `Format = "Hex"`; по умолчанию используется RGBA. Значение `Alpha` и аргумент прозрачности в callback по-прежнему находятся в диапазоне `0..1`.

Пример демонстрирует интерфейс: игровую логику подключают через callbacks.

## Проверка

С официальными CLI-инструментами Luau:

```powershell
luau-compile --null 'Nocturne(2).lua' 'Example(2).lua'
./tests/run.ps1 -Luau C:/path/to/luau.exe
```

Тесты выполняют реальный код библиотеки с минимальной имитацией Roblox API: ввод RGBA/HEX, отклонение ошибочных значений, callbacks, галерею между разными colorbox, мышь/касание, закрытие popup, блокировку контролов, размещение в маленьком окне, сохранение значений и создание всей демонстрации. Это проверка логики, а не движка рендеринга Roblox. Тест конфигурации использует имитацию сериализации, не проверяет JSON-парсер Roblox.

Для визуальной проверки в Roblox: откройте первую вкладку, проверьте оба нижних переключателя неба без прокрутки, откройте зелёный цвет в `extra`, смените формат через `Aa`, сохраните цвет и примените его из другого colorbox. Проверьте уменьшение окна и масштаб экрана.
